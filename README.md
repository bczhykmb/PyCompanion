# PyCompanion · Python 学习实验室

面向中职学生 Python 编程学习的教学实验平台，支持导师型与同伴型智能体、积极与中性情绪反馈的四组配置，提供编程练习、浏览器内 Python 运行和学习对话。

Vercel 部署请阅读 [VERCEL.md](./VERCEL.md)。线上使用静态页面与 API 函数，不能直接依赖本机的密码文件或 SQLite 文件；未配置云数据库时会显示明确提示。

学号登录与班级名单导入请阅读 [ROSTER.md](./ROSTER.md)。名单只在教师端导入数据库，不放入公开静态资源或GitHub。

各学习单元及自主练习的对话独立显示，模型只读取当前单元最近8轮已完成对话。切换单元保留各自问题草稿。学生界面只保留刷新旁一个下载按钮，在浏览器内生成当前单元ZIP，包含点击时编辑器里的Python文件与当前单元Markdown对话记录（提问、回复、代码、时间与状态）；无对话也可导出。教师完整记录导出不变。历史记录按已有task字段归属，不删除或迁移对话内容。

教师管理中的“四组智能体规则”可分别查看和编辑A/B/C/D规则，查看已有账号版本、历史版本并恢复默认。保存始终影响本组新账号；默认勾选“同步本组已有账号”，也更新学生与备用码的提示词和版本，保留组别、模式、模型参数及已有记录。处理中请求沿用已读取的规则。统一完成核对规则单独显示、仍由四组共用。演示回复不读取模型提示词。新对话保存实际系统提示词快照，只在教师完整导出中提供，不返回学生端；旧对话不补造快照。

本项目基于 [EduLab](https://github.com/PrideWood/edulab) 进行独立轻量化改造，现以 **PyCompanion** 名称维护。当前仓库为 [bczhykmb/PyCompanion](https://github.com/bczhykmb/PyCompanion)，不包含上游完整的 Next.js、Coze 和 PostgreSQL 应用；原项目说明请参阅上游仓库。

学生输入已导入的学号进入，也兼容教师分发的旧学习码。计网2541为D组、计网2542为C组、计网2543为B组、计网2532为A组，由服务端固定；这是按班级配置，不是随机分组。学号与班级仅向教师展示，学生端使用研究编号；平台不保存姓名。使用学号后数据属于可关联身份的编号记录，不能称为完全匿名。

当前默认演示模式，固定规则回复不是大模型，不能用于正式实验。代码可编辑、下载，并通过 Pyodide 314.0.7 在浏览器的独立 Worker 中真实执行，不在服务器执行。运行结果不等于大模型回复。

运行区提供运行、停止、输出/报错、预填多行标准输入。每次 input() 消耗一行；缺少输入时报 EOFError。每次运行使用新 Worker，不保留上次变量；运行超过 10 秒终止，加载超过 90 秒可重试，输出最多 16000 字符。仅支持 Python 基础及内置标准库，不承诺桌面图形界面或任意第三方包。构建从固定版本 npm 依赖 pyodide 314.0.7 读取解释器、WASM、标准库及清单，随网站发布至 /python-runtime/v314.0.7/；浏览器不依赖外部 CDN，也没有外部回退。首次下载约13MB，机房须实测连通与30人首次加载；未完成并发验收。Worker CSP 仅允许运行组件路径，不允许请求本站 API；不应视为对恶意代码的完整安全审计。

“询问代码”会直接发送当前代码，以及与代码和输入均匹配的最近运行状态和截断输出。运行结果来自学生浏览器，不能作为防篡改评分依据。未提问的本地运行不集中保存；刷新会丢失未保存草稿和运行结果。Pyodide 官方依据：https://pyodide.org/en/stable/usage/webworker.html 和 https://pyodide.org/en/stable/usage/streams.html 。

形象使用原项目的静态照片：A/B组为导师型（工程师导师），C/D组为同伴型（同学伙伴）；A/C中性反馈，B/D积极反馈。不需要CyberVerse、音视频服务或GPU。新学习码保存v2角色提示词快照；既有学习码的历史模型提示词不覆盖，真实模型体验应生成新码。演示回复仍会明确标记为规则回复。

集中保存匿名对话、提交代码、学习任务与时间。未实现前后测、量表或细粒度行为序列采集，不能视为完整研究平台。

八个单元提供零基础补全框架、分步提示、必做检查及选做扩展。真实模型依据当前任务要求和学生提交的代码、运行结果核对基础任务，确认时显示统一的“本单元基础任务已完成”标记；四组标记及完成标准相同。该标记属于模型对提交材料的判断，不是服务器自动判题或独立后测成绩。演示模式不自动确认完成。当前核对规则随服务更新生效，角色和反馈提示词仍使用学习码创建时的快照；新的零基础提示词需使用新生成的学习码。

本地需要 Node 22.13+：`npm install`、`npm run build`、`npm run dev`。本地自动生成教师访问凭证到被忽略的 `.env.local`，不要提交该文件。

线上使用托管数据存储，教师无需单独申请 PostgreSQL。学校能否访问托管域名必须现场验证。上线不等于已完成并发、安全与研究伦理验收。
